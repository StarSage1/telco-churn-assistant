# Verified end-to-end demo artifacts

These files were generated by the running local API with Ollama `qwen3:1.7b` available. They are evidence artifacts, not hand-authored model outputs.

## Single-customer flow

- `single/prompt-result.json`: exact successful natural-language prompt, extracted 19-field profile, prediction, and recommended action.
- `single/churnsignal-customer-assessment.pdf`: professional report returned by `POST /report` for that validated profile.

Result: **Churn**, **85.0%** estimated churn probability, **High** risk, against the **31%** action threshold.

## Bulk flow

- `bulk/input/churnsignal-10-test-customers.xlsx`: the uploaded 10-customer workbook.
- `bulk/churnsignal-assessment-package.zip`: the exact package returned by `POST /bulk-predict`.
- `bulk/package/churnsignal-10-test-customers-with-churn.xlsx`: cloned workbook with `Churn` and `Churn_Percentage` appended.
- `bulk/package/churnsignal-10-test-customers-findings.pdf`: summary and row-by-row marketing findings.
- `bulk/summary.json`: response summary and the ten model probabilities.

Result: **10/10** rows scored, **0** invalid, **3** predicted churn, **30.0%** portfolio churn rate.
